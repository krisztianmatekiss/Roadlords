A tényleges játék képernyőképére épül: két látható, négyzetrácsos város, egyenes út, visszafogott kövezett városalap, egyszerűbb festett épületek, a jelenlegi kezelőszervek elrendezése. A képen lévő feliratok és számok nem játékszabályok. Az L alakú épületek szabad sarkát és az irányváltozatokat külön kell kidolgozni; ezt a kép önmagában nem igazolja.
